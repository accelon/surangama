## 定址規則

| 欄位 | 規則 | 例 |
|---|---|---|
| `sid` | 全域句號，0 起算，固定四位 `S0000`–`S4889`；**新號，不再等於舊 `sutra.json.i`** | `S0048` |
| `addr` | 大正藏頁碼 ＋ 該頁第幾句：`T945.<page>.<NN>`；`NN` 從 01 起算，隨新切句重生 | `T945.19p106b.01` |

- `sid` 是**這張 view 的內部鍵**；在編號凍結前，不要把它當 canonical 寫進其他資料。
- 一般句頁內序 2 位；長咒語按 `　` 切後共用**起頁**，頁內序可能 3 位（目前最大 456），
  `addr` 只保證唯一，實際頁碼要看原文／`sid`。
- `sid` 和 `addr` 都依目前切句；重新切句要一起重生。
- 舊 3,732 句 → 新 4,890 句的對映在 `build/sentence-split-map.tsv`（`old_sid`、`new_first`、`new_last`、`parts`）。

### 軌號（track_id）

`data/tracks-zh.tsv` 是穩定軌號層：

- `track_id` = `<舊 sutra.json 句號>.<part>`，例 `S0000.1`、`S0046.3`。
- `base_sid` = 舊句號；`part` = 同一個舊句的第幾段。
- `display_sid` = 目前的 dense `S0000`，只作顯示／排序。
- 新增切點時，舊 `track_id` 保留；受影響的舊句才新增 part，其他軌不動。

這才是 crosswalk 的鍵；`display_sid` 會隨切分改。

  1. 切分規則定案（引號、`——`、咒語、S0000／S0046 手工切）；
  2. 抽樣校對 S0000、S0046、兩段咒語、`——` 邊界；
  3. 決定是否加 `base_sid`／`part` 兩欄，讓每一行都能追回 `sutra.json` 原句；

  「插號問題」會隨上級穩定而局部化，不是靠把 dense 號修得更聰明。

### 建議：穩定號 vs 順序號

現在的 `S0000`–`S4889` 是 **dense sequential**：每次新增一個切點，後面的號全部位移。
4,019 → 4,890 已經發生一次；這就是「句級編號要很慎重」的具體風險。

若要 freeze 編號，建議改成 **base + part**：

| 方案 | 例 | 好處 |
|---|---|---|
| `S<舊 i>.<part>` | `S0046.1` … `S0046.6` | 新增切點只改自己的 suffix，不影響其他句 |
| `S<舊 i>` ＋ `part` 欄 | `S0046`＋`part=1` | 舊 `sutra.json.i` 直接保留，crosswalk 最穩 |
| dense `ord` | `S0000`–`S4889` | 只作顯示／排序，不作 crosswalk 的鍵 |

換句話說：**crosswalk 用穩定號，畫面用順序號**。這樣以後再加切點，注疏的參照不會全部失效。

## 再切分規則（2026-11-05）

### 1. 引號前

在下列 pattern 的**開引號前**切開；前句保留 `：`／`。`，後句從引號起：

| pattern | 出現次數 | 例 |
|---|---:|---|
| `：「` | 248 | `佛告阿難：` ｜ `「汝我同氣…` |
| `：『` | 36 | `常自思惟：` ｜ `『此相非是…` |
| `：”` | 0 | 目前文本沒有 |
| `。“` | 0 | 目前文本沒有 |

### 2. 長句中的 `『…』`

雙括內 ≥20 漢字、且所在舊句 ≥30 漢字時，在 `『` 前再切一刀；目前 3 刀，都是把長引號的
lead-in 與引號內容分開：

| 前句 | 後句 |
|---|---|
| `我昔見佛與大目連…常言` | `『覺知分別心性…` |
| `「是經名` | `『大佛頂、悉怛多般怛囉…` |
| `「是經名『大佛頂…』，亦名` | `『救護親因、度脫阿難…` |

只切「開引號前」，不切 `』` 後；`』` 留在引號內容的末句，避免只有標點的碎片。

### 3. `——`

切在破折號**後**；句首的 `——` 是上一句的延續，不切（避免 `——` 自成一句）。
目前 8 刀。

### 4. 超過 2,000 字的咒語

按全角空格 `　` 切，空格本身不進句子：

| 舊句 | 內容 | 切出 |
|---|---|---:|
| S2434 | 大佛頂如來放光悉怛多鉢怛囉…神呪 | 436 句 |
| S2587 | 南無薩怛他…莎婆訶（含 j8 開頭） | 422 句 |

兩句共 858 句（淨增 856）。這些 parts 共用**起頁**，所以 `addr` 的頁內序會出現 3 位數。

## 注意

1. **密集列是錨定塌縮的指紋。** 新號 `S4847`（舊 S3691）有 1,894 個節點起點（蕅益 466＋灌頂 1,426＋…）、
   `S4856`（舊 S3700）有 1,805 個（交光 1,803）、`S4889`（舊 S3731）有 1,413 個
   （圓瑛 1,126＋簡 225＋極簡 60）。這不是真的有上千個科判從同一句開始，而是表號換算／內插
   把整棵子樹疊在同一句。要做可靠定址，應先處理這些節點的位置。
2. `nke` 只算「起點」，不含 `u2` 結尾；同一家的父節點與首個子節點常同句，所以 `nke`
   會大於實際獨立分段數。
3. 科判名稱保留來源用字（交光多用簡體），沒有改寫。
4. **已處理（2026-11-05）**：行首 `」`／`』` 已搬到前一句；舊 S0074→新 S0082 現在是
   `阿難白佛：`，舊 S0078→新 S0088 是 `是以渴仰，從佛剃落。」`，X265 node 19／20 已在內容句首。
   只有「阿難」「世尊」等短句先留著，不併。
5. **九家固定**：2026-11-05 06:39 之後 `kepan-data.js` 另加 `YK`（986 節點）；本表仍固定
