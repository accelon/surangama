# 提示詞：在閱讀器工作區加「楞嚴速查辭典」查詢頁

> 把下面整段貼給閱讀器（accelon26）工作區的 agent。資料已備好，**不要改資料格式**。

---

## 任務

在閱讀器加一個「**辭典／速查**」頁面（可從左欄或頂欄進入），資料來自
`D:\2026\surangama\data\glossary.json`。需求：可瀏覽、可搜尋過濾、每條有簡釋＋梵藏英對照、
點一條可看它在主文的所有出處，點出處直接跳到經文那一句。

## 資料格式（照用，不要改欄位名）

```json
{
  "schema": 1,
  "source": { "sutra": "T945", "sentences": 3732, "works": ["T1799", "..."] },
  "categories": [ { "id": "人物", "label": "人物", "count": 17 }, ... ],
  "entries": [
    {
      "id": "p-ananda",
      "term": "阿難",
      "aliases": ["阿難陀"],
      "category": "人物",
      "gloss": "佛陀堂弟、十大弟子之一，多聞第一；本經的當機者……",
      "sa": "Ānanda",
      "tib": "ཀུན་དགའ་བོ",
      "en": "Ānanda",
      "ref": null,
      "count": 458,
      "occurrences": [
        { "s": 8, "juan": 0, "page": "19p105c", "quote": "眾生以愛纏而起，故阿難以破惑為成道之基也。" }
      ],
      "truncated": true,
      "workHits": { "T1799": 559, "X275": 714, "LIB": 1362 }
    }
  ]
}
```

- `s`：主文句索引，對應 `data/sutra.json` 的 `sentences[i].i`；跳轉用 `s`，不要用 quote 比對。
- `page`：大正藏頁 id（例 `19p106b`），可直接顯示。
- `juan`：0 = 卷首序，1–10 = 正文卷次（0 的條目可加「卷首」標記）。
- `count`：主文出現總次數；`occurrences` 最多 200 筆，`truncated` 為 true 時要提示「只列前 200 筆」。
- `workHits`：在 11 家注疏中的出現次數（只有數字，無位置）。
- `ref`：呂澂《楞嚴百偽》條號（如「偽1–2」）；一般詞條為 null。
- `sa`／`tib`／`en` 可能是 null，顯示「—」，**不要自己補值**。
- 分類固定五類：人物、名詞、論點、呂澂批評、譯者版本。

## UI 需求

1. **入口**：左欄或頂欄一顆「辭典」；手機收在選單裡。
2. **版面**：桌面左清單（約 320px）＋右詳情；手機清單／詳情兩層切換。
3. **分類 chips**：全部／人物／名詞／論點／呂澂批評／譯者版本，各自顯示 count；點 chip 過濾。
4. **搜尋框**：即時過濾（120ms 去抖），比對 `term`、`aliases`、`gloss`、`sa`、`tib`、`en`、`ref`、`category`；
   支援中英梵藏；命中字串在清單與詳情裡高亮。
5. **清單項**：term（大字）＋分類色點＋`count` 次；有別名時小字顯示。
6. **詳情**：
   - term、aliases、分類
   - gloss（簡釋）
   - 對照列：梵 `sa`／藏 `tib`／英 `en`（null 顯示 —）
   - `ref`（呂澂條號）與 `workHits`（用注疏名顯示：T1799 子璿、X275 交光……）
   - 出處清單：每筆顯示 `juan`（卷首/卷N）、`page`、`quote`；點一筆 → 主文跳句並高亮。
7. **呂澂批評類**：`count` 為 0、沒有 occurrences，顯示「研究條目，無主文出處」。
8. **鍵盤**：↑↓ 移動清單、Enter 開詳情、Esc 回清單；搜尋框聚焦時 `/` 快捷鍵。
9. **記憶**：分類與搜尋字存 localStorage（key 例如 `surangama.glossary.v1`）。
10. **效能**：66 條、185 KB JSON，一次載入即可；不要每次搜尋重讀檔案。

## 驗收

- 開頁見 66 條、五個分類 count 正確（17／23／11／9／6）。
- 搜「阿難」→ 命中 1 條；詳情顯示 458 次、列出前 200 筆。
- 點第一筆出處 → 主文跳到 `19p105c` 那一句並高亮。
- 搜「tathāgata」或「如來藏」→ 命中如來藏條（比對 sa/gloss）。
- 切到「呂澂批評」→ 9 條，詳情顯示條號與「無主文出處」。
- 手機 390px 寬可正常切換清單／詳情。

## 不要做

- 不要改 `glossary.json` 的欄位名或結構；要加欄位先問。
- 不要在 UI 端重算 occurrences 或 workHits。
- 不要自己補梵／藏／英（null 就顯示 —）。
- 不要動 `data/sutra.json` 與 `data/works/`。
