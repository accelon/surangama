# 提示詞：閱讀器工作區加「楞嚴選注」UI（含速查辭典）

> 把整段貼給閱讀器（accelon26）工作區的 agent。資料已備好，**不要改資料格式**。

## 任務

在閱讀器加一個「楞嚴選注」頁：左邊主文（T945），右邊四個分頁——
**注疏／別譯／辭典／全文**（原本的「科判」分頁已于 2026-11-12 取消，見下方 §介面 註記）。辭典是這個站的賣點，要給它固定的位置與最快的入口。

## 資料

`D:\2026\surangama\site\data.js`，載入後是 `window.SURANGAMA`：

```js
{
  sutra: { no:'T945', title, sentences:[{ i, juan, page, text }] },
  zhu:   { T1799:{title,author,text}, X270:…, X275:…, X279:…, X285:…, X318:…, LIB:… },  // 6 家＋圓瑛
  ke:    { X265:{…}, X273:…, X278:…, X290:…, X304:…, X314:… },                          // 科判 6 部
  align: { <workId>: { <sentence i>: [[start,end,page], …] } },                          // 注疏片段
  english:{ label:'英譯・Charles Luk', juan:{ 1:'…', … 10:'…' } },
  glossary:{ categories:[{id,label,count}], entries:[…] }
}
```

- `sentences[i].page` 是大正頁 id；`align` 的 `start/end` 是 `zhu[id].text` 的字元位移。
- 辭典條目欄位：`term/aliases/category/gloss/sa/tib/en/ref/count/occurrences/workHits/truncated`，另有 `editorNote`（編者按）、`related`（相關條目 id 陣列）、`workLinks`（[{id,pos,quote}]，指向注疏／科判／當代文本的字元位移）。
- 範圍已定：**注疏 6 家＋圓瑛、科判 6 部、英譯 Luk**；BTTS 不收。

## 辭典（selling point）

1. **固定入口**：標題列一顆「辭典🔍」，任何時候按一下都切到辭典分頁並聚焦搜尋框；
   再按一次回上一個分頁。手機上收在選單第一項。
2. **搜尋**：即時過濾（120ms），比對 `term/aliases/gloss/sa/tib/en/ref/category`；中英梵藏都可；
   命中字串在清單與詳情高亮。
3. **清單**：`term`＋分類色點＋`count`；最多 72 條，一次渲染即可。
4. **詳情**：term、別名、分類、簡釋、**編者按**（`editorNote`，用不同底色標明「編者按」）、**相關條目**（`related`，渲染成可點 chips，點了直接切到那一條）、梵／藏／英（null 顯示「—」）、呂澂條號（`ref`）、
   `workHits`（用注疏名顯示：子璿 12、交光 8…）、**出處清單**。
5. **出處**：每筆顯示「卷N 頁碼」＋引文；點一筆 → 主文切到該卷、選中該句、捲到位置並高亮。
6. `truncated` 為 true 時提示「只列前 200 筆，共 N 筆」。
7. 當代見解類若有 `occurrences`，就是「被批評的經文」，點擊照樣跳主文；沒有出處的（如真經說）才顯示「研究條目，無主文出處」。
8. 記住上次分類與搜尋（localStorage `surangama.glossary.v1`）。

## 效率

- `data.js` 開發版約 4.1 MB；一次載入，不要重讀。
- 主文 3,732 句：用虛擬滾動或一次只渲染目前卷（325–486 句）。
- 注疏片段按需 slice，不要預先展開全部 11 家全文。
