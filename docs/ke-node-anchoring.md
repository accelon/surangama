# 節點級錨定：第一輪實驗（2026-11-04）

## 做了什麼

`scripts/build-ke-nodes.ts`：把子璿《義疏注經科》（X265）逐行拆成 2,331 個節點，
用 3-gram 共現找候選句、最長共同子串打分，再用**單調 DP**（節點順序不回頭）挑錨點，
沒錨到的節點在相鄰錨點之間插值。

產物：`data/ke-nodes.json`（2,331 個節點，含 `u` 位置與 `score`）。

## 結果：只有 179 個實錨（7.7%）

- 能錨到的，都是**標題本身就是經文原句**的節點，例如：
  - 「救護一切眾生離眾生相迴向」→ u=2681（score 12）
  - 「等一切佛迴向」「至一切處迴向」…十迴向名
- 錨不到的，是**編者描述語**，例如：「題目」「本文」「序說分」「證信序」「標類舉數」「總歎行德」「就疑難破」「會釋」——這些字串根本不在經文裡。
- 插值節點雖然有位置，但只是「平均分」，**語意上不可靠**（實測某節內 9 個節點剛好每 7 句一個，標題與所在句對不上）。

## 結論

單靠「科文標題 ↔ 經文」的字面比對，做不到節點級錨定；科文多數節點是結構標籤，不是引文。

## 可行的下一步（二選一）

### A. 用蒙鈔的「科文＋疏」交錯結構（推薦）

X287 蒙鈔正文有 **1,480 個【疏】** 標記，科文句就夾在疏文之間；疏文開頭常引經文。
做法：解析「經文引文 → 科文 → 疏」的順序，用引文對回經句，科文就繼承該位置。
預期錨定率會高很多，但要多寫一個蒙鈔解析器。

### B. 人工種子（快但有限）

在科文裡標 100–200 個關鍵節點的引文（例如每卷 10–20 個），其餘用單調插值。
準確度取決於種子密度；一天可做。
